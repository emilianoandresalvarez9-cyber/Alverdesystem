# PR-02 · fix(auth): login con Supabase local y redirección correcta por rol

**Rama:** `pr-02-login-local-y-roles` · **Parche:** `patches/PR-02-login-local-y-roles.patch` · **Depende de:** PR-01.

## Qué resuelve

Con `supabase start` (`http://127.0.0.1:54321`) el login no aparecía porque se exigía `https://` (CRÍTICO-01). Con 2 o más usuarios, el administrador terminaba en el catálogo (P8): `profiles.select().single()` no filtraba por usuario. Un empleado podía abrir `admin.html`.

## Cambios

- HTTP permitido solo hacia localhost, 127.0.0.1 o [::1]; HTTPS hacia cualquier host.
- Perfil filtrado por id; usuarios desactivados no ingresan.
- `AuthGate` con `requiredRole`; el enlace a Administración solo aparece para administradores.
- Sin conexión usa el último perfil conocido (o Empleado, el de menor privilegio).
