# PR-07 · feat(faltantes): avisar faltantes desde el catálogo, con o sin conexión

**Rama:** `pr-07-faltantes-offline` · **Parche:** `patches/PR-07-faltantes-offline.patch` · **Depende de:** PR-06.

## Qué resuelve

P12 (nuevo): RF-49 figuraba como cumplido pero no existía. `FaltantesPage` no se montaba en ninguna página y su botón marcaba un producto de demo con UUID fijo. Sin conexión encolaba un "ajuste de stock" sin cantidad que quedaba trabado para siempre.

## Cambios

- Botón "Avisar que falta" en cada producto del catálogo (2 toques).
- Tipo de operación offline `missing_item` (valor de enum en su propio archivo de migración).
- Dos avisos sin reponer = un faltante.
- Los avisos viejos trabados en la cola de cada equipo se convierten solos, con el mismo `localId`.

## Cómo se verificó

- `npm run verify` (guard, tipos, tests, build) y `npm run test:db:nodocker` (migraciones + pgTAP sobre PostgreSQL 16): en verde en este commit.
- `faltantes_offline_test.sql` (6), `legacy.test.ts` (1).
